Выноски для дизайнера

  1. Слоган над брендом (решение владельца 06.08): «Играй больше — плати меньше» первой строкой, под ним «ТУРБО» + бейдж «ИГРЫ». Читается по ходу трафика с 15–20 м.
  2. Бренд-блок: связка 1:1 с веб-страницей — «ТУРБО» белым без эффектов, «ИГРЫ» на лаймовом бейдже с наклоном −2°.
  3. Ценовой блок (взрослый уровень, глаза ~1600): белая плашка «ПАКЕТЫ» + чипы-квадратики «10 15 25 игр» + «от 350 ₽»; розовый бейдж «10 ИГР» сидит на НИЖНЕЙ грани рамки (визуальный мост между ценой и иконками).
  4. Иконки-приложения (детский уровень, глаза ~1050): крупные, с числом автоматов — числа Июня РЕАЛЬНЫЕ (17/10/8/2/45). Под ними клейм «Любой аркадный автомат» + «Игры не сгорают…» в две строки. Никаких других летящих иконок — это единственная графика.
  5. Фоновая стрелка: ОДНА цельная фигура (без внутренних разрезов), полная заливка #3d33a8 — заметно ярче фона, но под контентом. Рубленые прямые края — по референсу фирменной иконки `shark-eyes-icon-electric.svg` (приложена к ТЗ). Угол −8°, ВЫХОДИТ ИЗ-ПОД слова «ТУРБО» в верхней трети и указывает вправо ко входу за аэрохоккеем.
  6. Блок ТУРБО-ВТОРНИК: крупный, двумя строками («ТУРБО-ВТОРНИК» / «Турбо-часы весь день»), поднят к контенту. Ниже — чистый фон (воздух), у пола контента нет. Ссылок/QR на наклейке нет.
Спецификация Полотно: стекло 2350×3550 мм, ПОЛНАЯ заклейка, воздух по периметру ~220 мм внутри дизайна.
Лайм — фирменный #DFFF00 (взят из иконки shark-eyes-icon-electric.svg).
Тексты — ТОЛЬКО фразы согласованной веб-страницы, новых формулировок не вводить.
Голое «Турбо» не пишем — только ТУРБО-ИГРЫ / ТУРБО-ЧАСЫ / ТУРБО-ВТОРНИК.
Тему жвачек Turbo 90-х не используем (красный+жёлтый, клетчатый флаг, болид — нельзя).
Шрифты: Unbounded + Inter (Google Fonts, OFL). Цвета — плейсхолдеры фирменных.
